# Provider logo sources

The SVGs in this directory come from @lobehub/icons-static-svg version 1.94.0.

- Source: https://github.com/lobehub/lobe-icons
- Package: https://www.npmjs.com/package/@lobehub/icons-static-svg
- Package license: MIT

All product names, logos, and brands are property of their respective owners.

`windsurf.png` is the official white Windsurf symbol from the vendor's brand
guide, retrieved 2026-07-29:

- https://windsurf.com/brand
- https://exafunction.github.io/public/brand/windsurf-white-symbol.png

`amp.svg` is `icons/amp-color.svg` from the same @lobehub/icons-static-svg
1.94.0 package, retrieved 2026-10-15; the artwork is unchanged.

`muse.png` (Muse and Muse Code) and `grok-bot.png` are copied from the app's
`Sources/UsageDock/Resources/ProviderIcons/`, where they are documented as
official artwork supplied by the project owner on 2026-10-15 (presentation
only adapted: transparent background and centering for Muse, rounded corners
for the Grok Bot tile).

Factory and Augment have no published mark; the site draws the same letter
glyph the app falls back to, inline.

`codex-glyph.svg` and `codex-glyph-mono.svg` redraw the Codex mark exactly as
the app renders it (`CodexBrandGlyph` in `Sources/UsageDock/Views/BrandIcon.swift`):
the same seven lobes, the same `>_` stroke and gradient stops. The color file
matches the popover and Dashboard; the white mono file matches the default,
monochrome menu bar. The site and both READMEs use them; `codex.svg`
(Lobe Icons) stays in the folder but is no longer referenced.
