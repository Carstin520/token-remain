Human support

How can we help?

TokenRemain has no account system. Support is handled directly by email and public issue reports. Never send passwords, access tokens, API keys, cookies, or private prompts.

Email TokenRemain Support

Include these details

  • Mac, iPhone, or Watch model and OS version.
  • TokenRemain version and the affected surface or Provider.
  • The exact visible error message and steps to reproduce it.
  • A screenshot with personal information and credentials removed.

Mac companion and provider data

The Mac app is the source of real Provider data. The public Apple-notarized DMG supports Apple Silicon Macs running macOS 14 or later. Provider credentials remain on the Mac.

Download TokenRemain for Mac

Apple-device sync

The Mac and iPhone must use the same iCloud account with iCloud Drive and iCloud Keychain available. Sync can be enabled without granting notification permission.

When the iPhone app is active, it combines CloudKit change notifications with foreground reconciliation. A locked, suspended, force-quit, offline, or low-power device—and WidgetKit background refresh—cannot be promised a fixed delivery time.

No data yet

  • Confirm that TokenRemain on Mac shows current Provider data first.
  • Confirm the Mac and iPhone are signed in to the same iCloud account.
  • Open TokenRemain on iPhone and check the displayed provider capture time, not only the iCloud receipt time.
  • If real data is unavailable, Demo Mode remains clearly labeled and never represents a live Provider value.

Privacy or deletion help

Mac 伴侣 App 与 Provider 数据

Mac App 是真实 Provider 数据的唯一来源。公开 DMG 已通过 Apple 公证，支持运行 macOS 14 或更高版本的 Apple Silicon Mac。Provider 凭证始终留在 Mac。

下载 TokenRemain Mac 版

Apple 设备同步

Mac 与 iPhone 需要登录同一 iCloud 账号，并确保 iCloud Drive 与 iCloud Keychain 可用。启用同步不需要先授权通知。

iPhone App 活跃时，会结合 CloudKit 变更提示与前台兜底拉取。锁屏、挂起、强退、离线、低电量，以及 WidgetKit 后台刷新均无法承诺固定到达时间。

还没有数据

  • 先确认 Mac 版 TokenRemain 已经显示最新 Provider 数据。
  • 确认 Mac 与 iPhone 登录同一 iCloud 账号。
  • 打开 iPhone App，并查看页面显示的 Provider 采集时间，而不只是 iCloud 接收时间。
  • 真实数据不可用时，演示模式会始终明确标记，不会伪装成实时 Provider 数据。
