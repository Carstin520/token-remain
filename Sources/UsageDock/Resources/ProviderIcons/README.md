# Provider icon provenance

The SVG source files and corresponding 640 × 640 transparent PNG renderings in
this directory come from Lobe Icons 1.94.0:

- Source: https://github.com/lobehub/lobe-icons
- SVG package: https://www.npmjs.com/package/@lobehub/icons-static-svg
- PNG package: https://www.npmjs.com/package/@lobehub/icons-static-png
- Package license: MIT
- Retrieved: 2026-07-26

The filenames are normalized for TokenRemain's provider identifiers. The SVG
contents are unchanged from those packages. The app loads the PNG rendering
because macOS CoreSVG does not reliably rasterize every source SVG construct.
Brand names, logos, and trademarks remain the property of their respective
owners; inclusion here does not imply endorsement or transfer any trademark
rights.

`windsurf.png` is the official white Windsurf symbol published by Windsurf's
brand guide, retrieved 2026-07-29 from:

- https://windsurf.com/brand
- https://exafunction.github.io/public/brand/windsurf-white-symbol.png

`bailian.svg` and `bailian.png` use the Bailian color mark from the same
Lobe Icons 1.94.0 packages (`icons/bailian-color.svg`, `light/bailian-color.png`),
retrieved 2026-09-17. The source artwork is unchanged.

`amp.svg` / `amp.png` use `icons/amp-color.svg` / `light/amp-color.png` from
the same Lobe Icons 1.94.0 packages, retrieved 2026-10-15. The source artwork is
unchanged.

`muse.png` (Muse and Muse Code) and `grok-bot.png` are official artwork supplied
by the project owner on 2026-10-15. Only the presentation was adapted: Muse's
flat light-grey background was converted to transparency and the mark centered
on a square canvas; the Grok Bot app tile received rounded corners. No SVG source
exists for either. `grok-bot-mono.png` is a template derived from that tile (the
light sphere is the ink; the background and eyes are transparent) for monochrome
menu bars.

Factory and Augment have no Lobe Icons mark and use the app's fallback glyph.
