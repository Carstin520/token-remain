# 登录/凭证等待

用户发起登录或凭证验证后，界面展示等待状态；可以取消，超时或失败时控件恢复、提示准确，可以再次尝试，迟到的结果不会被提交。

**状态：** `draft`

## Sub-features

- `wait-visible`：等待中展示正在等待的步骤，防止重复提交。
- `wait-cancel`：用户取消后停止等待，可重新发起。
- `wait-timeout`：超时后停止转圈、恢复控件，提示下一步。
- `wait-retry`：再次尝试不会被旧结果关闭。
- `wait-late-result`：取消或超时后迟到的结果不写入凭证或缓存。

## How to get to it (user POV)

- 在数据源设置中对某个 provider 发起登录或凭证授权。

## Driving it with native macOS control

Preconditions:

- 已完成 Doctor 与授权的 Launch。
- 使用隔离请求，或已授权的真实流程；不为模拟验收写入真实凭证或缓存。

- **等待。** 发起登录或验证，观察等待提示和被禁用的控件。
- **取消或超时。** 取消，或等待超时，观察提示、控件恢复和旧数据保留。
- **再次尝试。** 重新发起，确认新一轮等待不会被上一轮结果关闭。
- **迟到结果。** 核对取消或超时后迟到的结果没有被提交。

## Gotchas

- 按 [DB-001](../../../../docs/design-boundaries.md#db-001) 区分取消与结果待确认。
- 系统弹窗未被实际关闭时，不声称已终止。
- 超时不等于凭证失效；不能一律要求重新登录。
