# TokenRemain robot logo redesign

## Round 1 — 2026-07-23

The first exploration preserves the existing purple, cyan, deep-navy pixel-art identity while changing the mascot proportions:

- head occupies 85–100% of the character;
- torso is removed or reduced to a tiny pedestal;
- facial display occupies roughly 55–65% of the head;
- eyes stay deliberately small so the display can support future mood states;
- concepts are compared with the same calm expression.

The numbered 5 × 2 board is saved as
`token-remain-robot-concepts-01-10.png`.

Suggested shortlist for refinement: 02, 03, 08, and 09.

## Round 2 — creative silhouettes

Round 2 deliberately moves beyond small proportion changes. Its ten directions
include CRT, floating probe, arcade cabinet, pixel ghost, astronaut helmet,
asymmetric satellite, handheld console, gemstone, panoramic scanner, and
stepped server-spirit architectures.

The board is saved as
`token-remain-robot-creative-concepts-01-10.png`.

Suggested shortlist for refinement: 03, 04, 05, 06, and 09.

## Round 3 — dimensional pixel pets

Round 3 uses the supplied Codex pet screenshot as a proportion and volume
reference without copying its blue cloud silhouette or face. Each TokenRemain
concept gains a tiny body, stubby limbs, layered shell depth, and stepped
pixel-cluster shading while preserving the purple/cyan identity and large mood
screen.

The board is saved as
`token-remain-dimensional-pet-concepts-01-10.png`.

Suggested shortlist for refinement: 01, 02, 07, and 08.

## Selected concept 10 — usage expression set

Concept 10 was selected for a complete 11-state remaining-quota expression
system. The robot identity stays fixed while face marks and small body poses
communicate each band:

| Remaining | State | Expression |
| --- | --- | --- |
| 96–100% | excited | star eyes, celebratory arms |
| 86–95% | happy | upward-caret eyes |
| 76–85% | bright | sparkle plus dot |
| 66–75% | calm | round dot eyes |
| 56–65% | focused | long bar eyes |
| 46–55% | neutral | short dash eyes |
| 36–45% | worried | inward slants and sweat pixel |
| 26–35% | tense | inward-facing chevrons |
| 16–25% | dizzy | square spiral eyes |
| 0.5–15% | anxious | worried eyes and tears |
| 0% | offline | dim X eyes and slumped pose |

Individual square assets and a review board are under
`selected-10-usage-states/`. These are design candidates and do not replace the
current runtime resources yet.

## Selected concept 10 — head-only app logo system

The app-logo version removes the entire body and keeps the selected cube head,
large mood screen, top cap, and cyan side status light. The robot remains violet
in every provider context. Provider identity moves to a separate segmented
meter layer:

- Claude: orange `#D97757`;
- Codex: blue `#4B9CFB`;
- compact space: show the provider with the lowest remaining quota;
- spacious layouts: show Claude above Codex while the face still follows the
  lower remaining value;
- one available provider: show its meter only;
- no available provider: show the neutral head without a live meter.

Assets, provider-meter variants, and review boards are under
`selected-10-head-logo-states/`. See `HEAD_LOGO_SPEC.md` for the responsive and
platform behavior.
